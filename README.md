# smartcitymagdeburg
Hackathon "Smart City Magdeburg" am 5. - 6. Juni 2026
Im Zuge der https://tomorrowlabs.magdeburg.de/

Veranstaltungsanmeldung : https://beteiligung.sachsen-anhalt.de/portal/magdeburg/beteiligung/themen/1003460

Bitte nur öffentliche Daten/open data unter Angabe der Quelle verwenden.
    -  Magdeburg Mietdaten: Eigene Berechnung, Datenquelle value-marktdatenbank.
    -  Statisikdaten aus KISS-MD: https://statistik.magdeburg.de/KISS-MD/ 
  

Ziel des Hackathons ist die Entwicklung eines Prototypen eines „Smart City“ Dashboards für die Stadt Magdeburg.
Bitte beachtet, dass ihr eure Prototypen mit Upload in das Github zur Nachnutzung durch die Landeshauotstadt Magdeburg und weitere freigibt.
